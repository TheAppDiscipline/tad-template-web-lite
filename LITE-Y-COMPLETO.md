# Edición Lite y producto completo

Esta comparación explica qué se ofrece gratis y qué se entrega al comprar. No necesitas comprar para usar el código de este repositorio.

| Área | Web Lite | Producto completo |
|---|---|---|
| Proyecto Web local | Sí | Sí |
| React, TypeScript y Vite | Sí | Sí |
| Persistencia en el navegador | Sí | Sí |
| Gate básico | Sí | Gates completos según cada plataforma |
| Vault guiado en español | No | Sí |
| Onboarding para principiantes | No | Sí |
| Templates Web, Mobile, Desktop y Extension | No | Sí |
| Agentes, skills y prompts | No | Sí |
| Orquestación y control por slices | No | Sí |
| Backends y controles de lanzamiento | No | Sí |
| Registro Vivo y actualizaciones v1.x | No | Sí |

La edición Lite sirve para comprobar el enfoque con un ejemplo pequeño. El producto completo sirve para seguir un proceso integrado desde la idea hasta el mantenimiento de una aplicación.
