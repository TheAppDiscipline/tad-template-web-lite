# Seguridad

No publiques contraseñas, tokens ni archivos `.env` en este repositorio.

Si encuentras una vulnerabilidad en el código mantenido por The App Discipline, envía una descripción reproducible a `support@theappdiscipline.com`. No incluyas credenciales ni datos personales en el reporte.

Este starter guarda el ejercicio en `localStorage`. No ofrece autenticación, sincronización, aislamiento entre usuarios ni un backend. Antes de añadir usuarios o información sensible, diseña y verifica esos controles de forma explícita.
